# Evolved Snake

## Vercel Link
https://你的-vercel-網址.vercel.app

## Design Concept
我的進化版 Snake 以原版貪吃蛇為基礎，加入會自行移動的敵方蛇障礙物，讓遊戲不再只是單純吃食物與避免撞牆。玩家需要同時觀察自己的路線、食物位置與敵方蛇的移動方向，預判下一步是否安全，因此增加了即時判斷與策略性。
為了讓手機玩家也能順利遊玩，遊戲加入虛擬搖桿，玩家可以直接點擊方向鍵控制蛇的移動，不一定要使用鍵盤，提升操作便利性與行動裝置的可玩性。若使用 MediaPipe，則可透過鏡頭偵測手勢來控制方向，讓玩家不只是按鍵操作，而是用肢體動作參與遊戲，我希望玩家玩完後能感受到，這不是普通 Snake 的重製版，而是一個結合移動敵人、手機操作與手勢互動的進化版 Snake。

## How My Version Is Different
我的版本加入了會移動的敵方蛇障礙物，玩家不只要吃食物，還要觀察敵方蛇的移動路線與方向。相比原版固定障礙物，整體遊戲更加動態，也更需要即時反應與路線判斷。

## How To Play
方向鍵控制蛇移動。
按下空白鍵開始遊戲。
避免撞到牆壁、自己的身體與移動中的敵方蛇。
吃到食物後分數會增加，遊戲速度也會逐漸提升。
