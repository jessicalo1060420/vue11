# Evolved Snake

## Vercel Link
https://vue11-rho.vercel.app/

## Design Concept
我的進化版 Snake 以原版貪吃蛇為基礎，加入會自行移動的敵方蛇障礙物，讓遊戲不再只是單純吃食物與避免撞牆。玩家除了要控制自己的蛇移動外，還需要觀察敵方蛇的行進方向與位置，預判下一步是否安全，避免在移動過程中被敵方蛇阻擋或碰撞，因此增加了更多即時反應與策略判斷的玩法。此外，遊戲加入虛擬搖桿設計，玩家可以直接點擊畫面上的方向鍵與開始鍵來控制蛇的移動，不一定需要使用鍵盤操作，使遊戲在手機與平板上也能方便遊玩，提升了整體操作性與可玩性。我希望玩家玩完後能感受到，這不只是傳統 Snake 的重製，而是一款加入動態敵人與行動裝置操作體驗的進化版 Snake。

## How My Version Is Different
我的版本加入了會移動的敵方蛇障礙物，玩家不只要吃食物，還要觀察敵方蛇的移動路線與方向。相比原版固定障礙物，整體遊戲更加動態，也更需要即時反應與路線判斷。

## How To Play
方向鍵控制蛇移動。
按下空白鍵開始遊戲。
避免撞到牆壁、自己的身體與移動中的敵方蛇。
吃到食物後分數會增加，遊戲速度也會逐漸提升。
